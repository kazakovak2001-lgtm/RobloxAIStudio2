## Pipeline Flow

```
GenerationRequest
  ↓
GenerationCoordinator.generate()
  ├── Stage 1: PLANNING
  │     └── PlannerEngine.createPlan()
  ├── Stage 2: EXECUTION
  │     └── PlanExecutor.executePlan() → AgentRegistry
  ├── Stage 3: ARTIFACT ASSEMBLY
  │     └── ArtifactAssembler.assemble() → dedup + verify
  └── Stage 4: VALIDATION
        └── PipelineIntegrityValidator.validate()
              ↓
        GenerationPackageBuilder.build()
              ↓
        ProjectStructureValidator.validate()
              ↓
        GenerationResult { success, session, package, metrics }
```

## Known Limitations

1. Package is in-memory only (no disk persistence yet)
2. Artifact extraction heuristics are basic (improve with schema-aware extraction)
3. E2E test with stub agents produces metadata artifacts (real agents produce scripts)
4. No WebSocket progress streaming from coordinator (available via trace.event)
