## Architecture

```
AgentOrchestrator.orchestrate(task)
  ├── CapabilityRegistry.getCapabilities()
  ├── AgentDependencyPlanner.createPlan()
  ├── for step in plan:
  │     AgentMessageBus.send(request)
  │     agent.execute()
  │     SharedAgentContext.setKnowledge()
  │     AgentMessageBus.send(response)
  └── AgentExecResult
```
