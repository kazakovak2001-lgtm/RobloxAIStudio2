## Backend Capabilities

The simulation engine provides a full gameplay analysis pipeline:

1. **Simulate** — Tick-based gameplay simulation (virtual player exploring mechanics)
2. **Playtest** — Analyze for friction, broken loops, dead ends, economy issues
3. **Metrics** — Extract structured metrics (completion rate, engagement, economy stability)
4. **Feedback** — Generate actionable improvement suggestions with grades (A-F)
5. **Refinement** — Determine if blueprint should be regenerated

## Architecture Decision: Workspace Panel (Option B)

**Chosen**: Add simulation as a panel inside the Workspace feature

**Reasoning**:

- Simulation requires a blueprint (generated by Workspace pipeline)
- User flow: Generate → Simulate → Review → Iterate
- Workspace already has 25 panels — adding one more is natural
- No new route/page needed
- Reuses existing Card, Badge, Button components

**Rejected alternatives**:

- Option A (New page): Would require passing blueprint between pages. Breaks workflow.
- Option C (AI Studio extension): AI Studio is for code generation, not game testing.
